# 마이크로비트 수동 부저 연결

실시간 측정에서 **‘자세 확인 필요’가 60초 연속 유지되면** 마이크로비트에 연결한 수동 부저가 반복해서 울립니다. 웹앱이 자세를 판정하고 시간을 재며, 마이크로비트는 USB로 받은 명령으로 소리를 냅니다.

## 1. 부저 연결

2핀 저전력 **수동 피에조 부저**를 사용합니다. 마이크로비트 전원을 분리한 상태에서 연결하세요.

| 부저 | 마이크로비트 |
|---|---|
| + (신호) | P0 |
| − | GND |

별도 전원을 연결하지 않습니다. P0를 만지거나 다른 장치와 공유하지 마세요. 전류가 많이 필요한 전자기 부저나 일반 스피커는 P0에 직접 연결하지 않고 드라이버 회로를 사용해야 합니다. 3핀 모듈은 위 2핀 배선과 다르므로 모듈의 전원·신호 사양을 확인하세요.

## 2. 마이크로비트에 넣을 코드

저장소 루트의 **[microbit-makecode.js](../microbit-makecode.js) 전체**가 업로드용 코드입니다. 기존 코드 일부에 덧붙이지 말고 전체를 교체하세요.

1. [MakeCode](https://makecode.microbit.org/)에서 새 프로젝트를 엽니다.
2. **JavaScript** 탭에서 기본 코드를 지우고 파일 전체를 붙여 넣습니다.
3. 다운로드한 `.hex`를 USB로 연결한 마이크로비트의 **MICROBIT** 드라이브에 복사합니다.
4. MakeCode의 장치 연결과 시리얼 모니터를 닫습니다.

코드는 micro:bit V1.5를 기준으로 작성했으며, 외부 부저 출력을 P0로 지정합니다. 수동 부저에 필요한 2,000Hz 신호를 0.2초씩 켰다 끄는 방식입니다.

## 3. 사이트에서 사용

1. 최신 `index.html`을 데스크톱 Chrome의 HTTPS 또는 localhost 환경에서 실행합니다.
2. 설정 → **장치 연결**에서 마이크로비트를 선택합니다. 충전 전용이 아닌 데이터 USB 케이블이 필요합니다.
3. **자세 확인 알림**, **마이크로비트 LED·부저**를 켭니다. **브라우저 알림 소리**는 PC 소리 설정이므로 꺼져 있어도 마이크로비트 부저는 동작합니다.
4. 먼저 **수동 전송 테스트 → 부저 테스트 (잠깐 울림) → 전송 테스트**로 배선을 확인합니다. 1분을 기다리지 않고 최대 약 3초간 울립니다. **대기 LED → 전송 테스트**로 즉시 끌 수도 있습니다. 측정 중에는 일시정지 후 테스트하세요.
5. 좋은 자세와 비교 자세가 포함된 **2개 이상의 클래스를 학습한 Pose Model**을 불러오고 좋은 자세 클래스를 선택합니다.
6. 실시간 측정을 시작합니다. 자세 확인 필요 상태가 안정화된 뒤 60초 연속 이어지면 부저가 반복해서 울립니다.

**불러온 모델의 클래스가 하나뿐이면 자세를 비교할 수 없으며 부저도 울리지 않습니다.** 좋은 자세와 비교 자세를 학습한 2개 이상 클래스의 모델을 사용해야 합니다. 앱의 ‘자세 확인 필요’는 선택한 좋은 자세 클래스의 점수가 기준보다 낮다는 의미입니다.

## 4. 동작 기준

- 부저 기준은 **60초 고정**입니다. 기존에 저장한 화면 알림 시간이 10초이거나 다른 값이어도 부저 기준은 바뀌지 않습니다.
- 좋은 자세로 바뀌거나, 사람이 보이지 않거나, 분석이 끊기면 연속 시간이 초기화되고 부저가 꺼집니다. 서로 떨어진 주의 구간을 합산하지 않습니다.
- 일시정지·측정 종료·알림 끄기·마이크로비트 LED·부저 끄기도 부저를 정지합니다. 정상적인 시리얼 연결에서는 다음 정지 명령이 전달될 때 꺼집니다.
- 사진 피드백에서는 부저가 울리지 않습니다.
- 브라우저가 부저 명령을 약 1초마다 갱신합니다. 마지막 부저 명령 후 3초 동안 갱신이 없으면 마이크로비트가 자동으로 소리를 끕니다. 탭 종료·USB 통신 단절에도 계속 울리지 않도록 하기 위한 처리입니다.
- 수동 부저 테스트는 위 60초 조건을 의도적으로 건너뛰는 배선 확인 기능입니다.

## 5. 통신과 검증

기존 USB 시리얼 115200bps와 두 줄 프레임을 그대로 사용합니다. 아래 **상태 프레임**으로 부저를 켜며, 같은 문자열이 AI 클래스 이름으로 들어와도 부저 명령으로 해석하지 않습니다.

```text
FRAME:STATUS
STATUS:BUZZER
```

`STATUS:GOOD`, `STATUS:CHECK`, `STATUS:WARNING`, `STATUS:UNKNOWN`은 부저를 정지합니다. `STATUS:WARNING`은 기존 화면 알림 시점의 LED 전용 상태이고, 부저 알림과 구분합니다. 기존 펌웨어는 `STATUS:BUZZER`를 알 수 없으므로 사이트와 펌웨어를 함께 갱신해야 합니다.

자동 검사는 60초 경계, 연속 시간 초기화, 실제 웹앱 프레임을 MakeCode 수신 코드에 전달하는 흐름, 반복 알림과 정지, 통신 갱신 중단 시 자동 정지를 검증합니다. 물리 부저의 발음, 실제 카메라 추론과 MakeCode 장치용 컴파일은 실물 환경에서 별도로 확인해야 합니다.
