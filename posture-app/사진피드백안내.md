# 매일 사진 자세 피드백

## 사용할 수 있는 기능

- 카메라로 직접 촬영하거나 JPG·PNG·WebP 사진 파일 선택(최대 15MB)
- 사진 미리보기, 분석 방향의 좌우 반전 선택
- 기존 Teachable Machine **Pose Model**을 이용한 단일 사진 추론
- 실제 클래스 이름을 보존한 점수 표시와 좋은 자세 기준 비교
- 사진에서 보이는 어깨선 기울기·코와 어깨 중심의 좌우 차이에 따른 참고 안내
- 날짜·메모·사진·당시 모델 설정·피드백을 함께 저장
- 날짜 필터, 같은 날짜의 여러 기록, 상세 사진과 피드백 조회
- 사진 내려받기, 사진 기록 JSON 백업/복원, 개별/전체 삭제

## 사용 순서

1. 웹앱을 Chrome의 HTTPS 또는 localhost에서 엽니다.
2. **매일 사진 피드백** 메뉴를 선택합니다.
3. 사진 선택으로 파일을 고릅니다. 직접 촬영하려면 카메라 켜기 → 권한 허용 → 사진 찍기를 사용하세요. 촬영 후 카메라 트랙을 종료합니다. 다른 화면으로 가거나 탭을 숨겨도 사진 촬영용 카메라는 꺼집니다.
4. 오늘 또는 이전 날짜를 지정하고 메모를 입력합니다. 미래 날짜는 저장할 수 없습니다.
5. 필요하면 ‘분석할 때 좌우 반전’을 켭니다. 학습 시 방향과 맞추기 위한 것으로 저장 사진의 픽셀 방향은 바꾸지 않습니다.
6. 사진 피드백 받기를 누릅니다. 모델이 아직 없으면 설정의 기본 모델을 먼저 다운로드합니다. 모델이나 좋은 자세 클래스는 기존 설정 화면에서 변경할 수 있습니다.
7. 결과를 확인한 뒤 날짜별 기록에 저장을 누릅니다. 저장 성공 전까지 미리보기를 유지합니다. 저장 실패 시 안내를 확인하고 공간·권한을 조정한 뒤 재시도할 수 있습니다.
8. 아래 사진 기록에서 날짜로 찾고 사진을 눌러 당시의 사진·메모·피드백을 확인합니다. 모델을 나중에 바꿔도 저장된 피드백을 소급해서 바꾸지 않습니다.

실시간 측정 중에는 먼저 종료 및 저장을 눌러 주세요. 모델이 겹쳐 실행되거나 카메라 자원을 동시에 사용하지 않도록 한 앱의 동작입니다.

## 피드백의 의미

사진은 `estimatePose()`와 `predict()`를 한 번씩 실행합니다. 사진에 대해 같은 장면을 반복 분석한 결과를 여러 시점의 자세 안정성으로 표현하지 않습니다. 원본의 전체 구도가 보존되도록 분석용 정사각형 캔버스 안에 비율을 유지해 맞춥니다.

상체가 충분히 보이고 두 개 이상의 클래스를 학습한 모델에서 좋은 자세 클래스를 지정했을 때, 해당 점수가 설정 기준 이상이면 ‘좋은 자세 클래스와 유사해요’를 표시합니다. 기준 아래면 촬영 환경과 자세를 함께 확인하도록 안내합니다. 클래스 하나만 있는 모델은 높은 점수라도 자세 판정을 보류합니다. 사람이 보이지 않는 사진에서는 클래스 점수를 보여 주지 않습니다.

어깨선 기울기는 양쪽 어깨 관절점의 화면상 기울기입니다. 머리 좌우 차이는 코의 가로 위치와 양쪽 어깨 중심의 거리를 어깨 너비로 나눈 값입니다. 관절점이 불확실하거나 어깨 너비가 너무 작으면 수치를 만들지 않습니다. 안내에 사용하는 8°·22%는 앱의 참고용 휴리스틱이며 검증된 의학적 정상/비정상 기준이 아닙니다. 카메라 기울기·촬영 방향·거리 때문에 달라질 수 있습니다. 이 기능은 거북목, 척추 변형, 질환이나 통증을 진단하지 않습니다.

앉은 환경을 돌아보는 안내는 기존 [OSHA 자세 가이드](https://www.osha.gov/etools/computer-workstations/positions)와 연결된 앱의 자세 가이드 화면을 참고합니다. 모델 연동은 [Google의 공식 Pose Library](https://github.com/googlecreativelab/teachablemachine-community/tree/master/libraries/pose)를 사용합니다.

## 사진과 개인정보

사진 파일은 브라우저에서 디코딩하고 긴 변 최대 1280px의 JPEG로 다시 만듭니다. 별도 썸네일도 생성합니다. 파일의 원래 EXIF 등의 메타데이터를 복사하지 않습니다. 원본 고해상도 사진이 필요하면 별도로 보관하세요.

저장 버튼을 누른 사진만 브라우저의 IndexedDB `bareungyeol.photos.v1`에 보관합니다. `entries`에는 날짜·메모·피드백, `images`에는 이미지와 썸네일을 넣고 **하나의 트랜잭션**으로 저장하거나 삭제합니다. 두 저장소 중 한쪽만 성공했다고 안내하지 않습니다. 기존 실시간 기록의 localStorage 형식은 바꾸지 않습니다.

GitHub에는 앱 코드만 저장하며 사진은 전송하지 않습니다. 서버 업로드, 계정 로그인, 기기 간 동기화는 이 변경에 포함하지 않습니다. 브라우저 데이터 삭제·비공개 창 종료·사이트 주소 변경으로 사진에 접근하지 못할 수 있으므로 사진 기록 백업을 내려받으세요. 사진 백업에는 이미지 자체가 들어 있으므로 공유할 때 주의하세요.

사진 백업은 이 화면의 사진 기록 백업 버튼을 사용합니다. 기존 실시간 JSON 백업과 별도입니다. 복원 시 같은 ID는 백업 값으로 갱신하고 다른 ID는 추가합니다. 사진 백업 복원은 100MB·1000개 이하를 지원합니다. 저장소 용량을 초과하면 오류를 표시하며 자동으로 기존 기록을 삭제하지 않습니다. 기존 실시간 기록 보관 기간 설정으로 사진을 자동 삭제하지 않습니다.

## 테스트 범위와 수동 점검

자동 검사:

- 기존 시간·통계·알림·저장·시리얼 모의 검사 25개
- 사진 관절점 수치, 단일 클래스 제한, 미인식 처리, 기준값 경계, 원문 클래스 보존, 날짜 검증, 백업 메타데이터 검증, HTML 이스케이프, 실시간 데이터 분리 검사 14개

브라우저에서 확인:

- 새 메뉴와 사진 화면, 빈 기록 상태
- 손상 PNG 선택 시 오류 안내 및 재선택
- 사람이 없는 합성 PNG를 실제 기본 모델로 추론 → 판정 보류
- 날짜·메모·사진·피드백 저장, 새로고침 후 복원 및 상세 보기
- 사진과 피드백이 함께 들어 있는 JSON 백업 다운로드

실제 사용자 자세 분류 품질이나 실제 웹캠 촬영·장치 동작을 검증했다고 주장하지 않습니다. 다음 사항은 사용하는 환경에서 점검하세요.

1. 실제 카메라 권한 허용·거절, 장치 해제, 촬영·중지, 탭 숨김 때 카메라 해제
2. 사람과 머리·어깨·상체가 충분히 보이는 다양한 사진의 인식 품질
3. 충분히 학습한 두 클래스 이상 모델에서 기준 위/아래 피드백
4. 같은 날 여러 사진, 지난 날짜 저장, 날짜 필터, 개별 삭제 취소·확인
5. 사진 백업을 다른 브라우저/주소에서 복원하고 사진·메모·피드백 확인
6. 저장 공간 부족·IndexedDB 차단·손상 백업 등 예외 처리
7. 사진을 분석해도 기존 실시간 통계·알림·마이크로비트 상태가 바뀌지 않는지 확인

사람이 없는 합성 테스트 사진은 개인 사진 대신 오류·저장 흐름을 검증하기 위한 자료이며 제품 기본 기록으로 넣지 않았습니다.

## 좋은 자세 오판정을 줄이기 위한 변경

- 모델의 `Class 1`을 좋은 자세로 자동 지정하지 않습니다. 업데이트 후에는 설정에서 실제로 좋은 자세를 학습한 클래스를 다시 선택해야 합니다. 한 번 직접 선택한 클래스는 해당 모델 설정으로 저장합니다.
- 사진은 정면의 눈·코·양쪽 어깨와 팔 또는 허리가 충분히 인식되어야 합니다. 측면·가림·멀리 있는 인물은 판정을 보류합니다. 실시간 측정보다 엄격한 사진용 인식 조건을 사용합니다.
- 좋은 자세 표시에는 좋은 자세 클래스가 최상위이며 최소 90% 분류 점수(설정 기준이 더 높으면 그 기준)를 받고, 사진 정렬 정보도 확인되어야 합니다. 점수가 애매하면 확인 필요로 단정하는 대신 판정을 보류합니다. 이 수치와 어깨 8°·머리 좌우 차이 22%는 검증된 임상 기준이나 정확도 보장이 아닌 보수적인 앱 규칙입니다.
- 좋은 클래스 점수가 높더라도 정렬 정보가 없거나 안내 범위를 벗어나면 좋은 자세로 표시하지 않습니다. 촬영 각도 때문에 정렬이 달라질 수도 있으므로 이 경우 나쁜 자세로 확정하지 않습니다.
- 정면 사진의 좌우 정렬만으로 앞으로 숙인 목이나 굽은 허리를 판별할 수 없습니다. 실제 사용 조건에서 다양한 좋은/비교 자세를 충분히 학습하고, 학습에 쓰지 않은 실제 사진으로 모델을 검증해야 합니다. 이번 변경만으로 실제 분류 정확도가 높아졌다고 주장하지 않습니다.
- 기존 기록은 원래 사진과 피드백을 유지하고 이전 기준임을 표시합니다. 사진 상세 → **이 사진 다시 분석** → **사진 피드백 받기** → **날짜별 기록에 저장** 순서로 새 기준을 적용할 수 있습니다. 저장하기 전에는 기존 기록을 바꾸지 않으며, 저장하면 같은 ID의 기록을 갱신합니다.

## 옆모습 사진 측정

1. 사진을 선택하거나 촬영한 뒤 **사진 방향 → 옆모습**을 선택합니다.
2. 카메라를 몸의 측면과 직각으로 수평하게 두고, 보이는 쪽 귀·어깨·골반을 한 장에 담습니다. 왼쪽·오른쪽 옆모습을 모두 지원합니다.
3. **사진 피드백 받기**를 누르면 신뢰도가 충분한 같은 쪽 귀·어깨·골반을 연결해 표시합니다. 사진 위 관절점이 실제 위치와 맞는지 먼저 확인하세요.
4. 귀–어깨선의 수직 기울기, 어깨–골반으로 본 상체선의 수직 기울기, 귀–어깨 수평 거리/어깨–골반 선 길이 비율을 확인하고 저장할 수 있습니다.
5. 사진 방향과 측정값은 기록·상세 보기·백업/복원에 포함됩니다. **이 사진 다시 분석**도 저장된 사진 방향을 복원하며 같은 기록을 갱신합니다. 기존 정면 기록은 계속 열 수 있습니다.

옆모습에서는 양쪽 눈·어깨를 요구하는 정면 인식 조건을 사용하지 않습니다. 한쪽 귀·어깨·골반이 선명해야 하며, 관절이 가려지거나 너무 작거나 정면에 가까운 사진이면 측정을 보류합니다. 관절 감지 신뢰도와 기하 검사는 앱의 품질 규칙으로 실제 자세 정확도를 보증하지 않습니다.

**옆모습은 화면상 정렬 측정 모드입니다.** 정면으로 학습한 Teachable Machine 분류 점수를 옆모습의 좋은/나쁜 자세로 재사용하지 않습니다. 이 모드에서는 클래스 점수를 판정에 쓰지 않고, 좋은 자세 클래스를 선택하지 않아도 관절 측정은 가능합니다. 목뼈·척추의 실제 각도나 거북목 진단용 각도가 아니며, 앞으로/뒤로 기울었는지의 확정 판정도 하지 않습니다. 같은 카메라 높이·거리·방향에서 자신의 기록을 비교하는 데 사용하세요. 실시간 측정과 마이크로비트 알림은 이 사진 모드 변경의 영향을 받지 않습니다.
