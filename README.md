# posturerobot · 바른결

Teachable Machine Pose Model과 마이크로비트를 이용하는 자세 습관 관리 웹앱입니다. `index.html` 하나로 실행하며 서버나 API 키가 필요하지 않습니다.

## 매일 사진 피드백

왼쪽 메뉴의 **매일 사진 피드백**에서 다음 순서로 사용합니다.

1. **사진 선택**으로 JPG·PNG·WebP 파일을 올리거나, **카메라 켜기 → 사진 찍기**로 촬영합니다.
2. 날짜와 선택 사항인 메모를 입력합니다.
3. **사진 피드백 받기**로 포즈 모델의 분류 결과와 사진에서 확인할 점을 봅니다.
4. **날짜별 기록에 저장**을 누르면 사진과 피드백을 함께 보관합니다.
5. 날짜로 기록을 찾고, 사진을 눌러 당시 피드백을 다시 확인합니다. 같은 날짜에 여러 장을 저장할 수 있습니다.

사진은 **현재 기기의 현재 브라우저**에 저장됩니다. GitHub나 외부 서버로 사진을 업로드하지 않으며, 여러 기기 사이에 자동으로 동기화되지 않습니다. 사진 기록 백업/복원과 개별/전체 삭제를 제공합니다. 사진을 저장하면 긴 변을 최대 1280px로 줄이고 JPEG로 다시 만듭니다.

사진 한 장은 실시간 측정과 분리됩니다. 사진을 분석해도 실시간 자세 유지 시간·알림 횟수·좋은 자세 비율이나 마이크로비트 상태를 바꾸지 않습니다. 실시간 측정을 종료한 뒤 사진 촬영·분석을 사용하세요.

모델 클래스가 하나뿐이거나 상체가 충분히 보이지 않으면 AI 자세 판정을 보류합니다. 사진의 어깨선·머리 중심 안내는 촬영 각도에 영향을 받는 화면상 참고 정보이며 질환·거북목·척추 상태를 진단하지 않습니다.

## 실행과 배포

데스크톱 Chrome에서 HTTPS 또는 localhost로 실행하세요. GitHub Pages나 Netlify 같은 정적 호스팅에 루트의 `index.html`을 배포할 수 있습니다. GitHub 저장소의 소스 보기 화면에서는 웹앱이 실행되지 않습니다. 다른 주소로 옮길 때 실시간 기록 JSON과 사진 기록 백업은 각각 내보내고 복원하세요.

## 검사

추가 패키지 없이 Node.js에서 실행합니다. 날짜 관련 검사는 `Asia/Seoul` 시간대를 기준으로 합니다.

```powershell
$env:TZ = 'Asia/Seoul'
node tests/core.test.cjs
node --test tests/photos.test.cjs
```

실시간·마이크로비트·부저 모의 검사 39개, 사진 피드백·입력 검증 검사 14개를 포함합니다. 브라우저에서는 손상 이미지 처리, 테스트 이미지의 실제 모델 추론, 사진·메모·피드백 저장 및 새로고침 복원, 상세 보기와 사진 백업 다운로드를 확인했습니다. 실제 사용자 자세의 정확도, 실제 웹캠 촬영과 마이크로비트 하드웨어 동작은 별도로 시험해야 합니다.

## 마이크로비트 수동 부저

주의 상태가 60초 연속 유지되면 P0·GND에 연결한 수동 피에조 부저가 반복해서 울립니다. 좋은 자세·미인식·일시정지·종료 시 정지하고, 부저 명령 갱신이 3초간 끊겨도 멈춥니다. [전체 업로드 코드](microbit-makecode.js)와 [배선·사용 방법](posture-app/부저연결안내.md)을 확인하세요. 사이트 설정의 부저 테스트로 바로 확인할 수 있습니다. 기본 모델은 `https://teachablemachine.withgoogle.com/models/jXNqYPxoH/`이며 불러온 뒤 좋은 자세 클래스를 지정해야 합니다.
